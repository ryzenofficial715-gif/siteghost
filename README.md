**Web Ripper + WAF/404 Bypass + Asset Downloader**

> SHADOWREAPER Project

---

## 🔥 Fitur

- **Bedah HTML** — Ambil source code lengkap
- **Bypass WAF** — X-Forwarded-For, Bot, Mobile, Cloudflare headers
- **Bypass 404** — Path manipulation, URL encoding
- **Rip Endpoints** — Ekstrak API, fetch, axios calls
- **Rip API Keys** — Tangkap token, key, password
- **Download CSS/JS** — Ambil isi file eksternal
- **Download All** — Semua asset jadi 1 file
